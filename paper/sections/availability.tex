\section{Data and code availability}
Code, configuration and scripts to reproduce every number in this paper are available at \url{https://github.com/Ruskinkot1/noise-ceiling-mol} \todo{make the repository public, add a licence and the commit hash of this version}. The pipeline (\texttt{scripts/run\_all.sh}, \texttt{scripts/run\_full.sh}) downloads the data from the ChEMBL API, so results may change with future ChEMBL releases; the processed per-task files (molecules, labels, number of documents, year of first report) and all predictions will be deposited with this version \todo{archive and DOI}. ChEMBL data are distributed under the Creative Commons Attribution-ShareAlike 3.0 licence, and derived data are released under the same terms.
