\section{Data and code availability}
Code, configuration, the extracted ChEMBL data and all results of this paper are available at \url{https://github.com/Ruskinkot1/noise-ceiling-mol/tree/preprint-v2} (tag \texttt{preprint-v2}; the first version of this work is tagged \texttt{preprint-v1}); the \texttt{README} describes how to regenerate every table and figure from the stored results in minutes, or to rerun the models in about four days on a laptop. The repository contains the per-task molecule and measurement files (identifier, SMILES, label, number of documents, year of first report), the per-document measurements, and the predictions of every model, split and seed. The pretrained-model embeddings (about 400\,MB) and the registry of public benchmark molecules used for decontamination are not stored but are regenerated by \texttt{scripts/06\_embed\_foundation.py} and \texttt{scripts/build\_registry.py}. Because \texttt{scripts/01\_extract\_chembl.py} queries the live ChEMBL API, rerunning the extraction will give a later release than the ChEMBL~37 snapshot used here. The same snapshot is archived at \url{https://doi.org/10.5281/zenodo.23572957}. Dependencies are pinned where a version change would alter results: the MoLFormer-XL revision we use requires \texttt{transformers}~4.51.3, and frozen-embedding scores are comparable across tasks only within one library version.
