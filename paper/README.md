**Рабочее название:** *Do Foundation Chemical Models Beat Small Models on Data They Have Not Seen? A Noise-Ceiling Evaluation on Fresh ChEMBL Benchmarks.*
**Трек:** NeurIPS Datasets & Benchmarks. **Статус:** черновик, результатов экспериментов нет.

| Файл | Что внутри |

| `main.tex` | Текст статьи на английском: аннотация, введение, связанные работы, формализация (модель шума, потолок, доля потолка, утечка, гипотезы H1–H4), построение датасета, протокол, результаты (заглушки), ограничения |

## Сборка

В окружении, где это писалось, LaTeX не был установлен, поэтому **файл не компилировался**. Перед сборкой:

```bash
cd paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Для подачи нужно подключить официальный стиль NeurIPS (`neurips_2026.sty`, в репозиторий не включён) вместо блока `\documentclass` в начале `main.tex`.
