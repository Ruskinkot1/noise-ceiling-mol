# Спринт на 40 минут, 5 участников

Проект: **noise-ceiling-mol** (потолок шума в бенчмарках молекулярных свойств).

**Цель:** за один сеанс собрать входные данные для этапов 0–1: проверка новизны и отбор данных. Каждый работает самостоятельно, в конце общая сводка.

## Тайминг

| Время | Что делаем |
|---|---|
| 0–3 мин | Постановка задач |
| 3–33 мин | Самостоятельная работа |
| 33–40 мин | Сводка, по 1,5 мин на человека |

## Задачи

| # | Участник | Задача | Результат |
|---|---|---|---|
| 1 | Новизна A | Найти работы 2022–2026 про noise ceiling, inter-assay variability, label noise в ChEMBL и TDC | 5–8 статей: название, год, суть, отличие от нашей идеи, ссылка |
| 2 | Новизна B | Найти работы про сравнение предобученных молекулярных эмбеддингов с ECFP и про activity cliffs | 5–8 статей в том же формате и вывод: свободна ли наша формулировка |
| 3 | Данные ChEMBL | Составить запрос или скрипт, который находит молекулы с повторными измерениями одного эндпойнта из разных документов. Прогнать на 3–5 мишенях | Запрос и таблица «мишень → число молекул с ≥2 источниками» |
| 4 | Модели | Составить список открытых предобученных эмбеддингов, которые запускаются локально (ChemBERTa, MolFormer, Uni-Mol, GROVER и т. д.). Проверить лицензию, размер, способ инференса | Таблица: модель, лицензия, размер, запускается ли на ноутбуке, ссылка |
| 5 | Метрика и сплиты | Описать формулу «доли потолка» и протокол оценки: как считать потолок по повторам, как делать скэффолдный и временной сплиты, сколько сидов | Страница с формулами и пошаговым протоколом |

## Правила

- Каждый ссылается на источник, непроверенное помечает «не проверено».
- Результат кладётся в общий документ, в свой раздел, не позже 33-й минуты.
- Если задача выполнена раньше срока, взять запасную: выяснить, есть ли в ChEMBL документированные данные об ошибке измерений (стандартные ошибки, поля с комментариями).

## Итог сеанса (последние 7 минут)

1. Решение по новизне: идея свободна, занята частично или занята.
2. Число доступных мишеней с повторами: хватает ли минимума в 15.
3. Список моделей для этапа 3.
4. Назначение задач на следующую неделю.
